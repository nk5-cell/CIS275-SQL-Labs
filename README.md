# Lab 5: Advanced SQL Queries, CTEs, and Built-In Functions

---

## Overview

This lab focuses on advanced querying techniques in Transact-SQL (T-SQL), including Common Table Expressions (CTEs), set operations (`EXCEPT`), subqueries, conditional logic (`CASE`), and built-in T-SQL scalar functions (`DATENAME`, `DATEPART`, `DATEDIFF`, `CONCAT_WS`, `FORMAT`, `CONVERT`).

---

## Lab Problems & Query Implementations

### Question 1: Single-Item Orders Analysis

* **Database:** `ProductOrders`
* **Objective:** Identify orders that consist of exactly one line item using a subquery with `GROUP BY` and `HAVING COUNT(ItemID) = 1`.

### Question 2: Vendor Credit Summary

* **Database:** `AP`
* **Objective:** Aggregate credit totals and invoice counts per vendor for vendors with positive credit balances using `GROUP BY`, `HAVING`, and currency formatting via `FORMAT()`.

### Question 3: Date-Formatted Order Aggregations

* **Database:** `ProductOrders`
* **Objective:** Format order dates into long form (`Monday, December 21, 2015`) using `DATENAME()`, concat customer names with `CONCAT_WS()`, and filter orders within a specific date range.

### Question 4 & 5: Year-over-Year Customer Retention Comparison

* **Database:** `ProductOrders`
* **Objective:** Find customers who placed orders in 2014 but had no orders in 2016.
* **Question 4 Approach:** Solved using nested `IN` and `NOT IN` subqueries.
* **Question 5 Approach:** Refactored using Common Table Expressions (CTEs) and the set difference operator `EXCEPT`.

### Question 6: Quarterly Sales Breakdown (2015)

* **Database:** `ProductOrders`
* **Objective:** Extract calendar quarters using `DATEPART(qq, OrderDate)` to summarize order counts and total items purchased per customer in 2015.

### Question 7: Subquery Filtering against Category Averages

* **Database:** `MyGuitarShop`
* **Objective:** Retrieve products with a list price greater than or equal to the average list price of items in Category 3 (`AVG()` subquery filter).

### Question 8: Shipping Delay Analysis & Conditional Handling

* **Database:** `ProductOrders`
* **Objective:** Calculate shipping delay in days using `DATEDIFF()` and handle unshipped orders (`NULL` values) by returning `9999` using a `CASE` statement. Displayed top 10 most delayed orders.

### Question 9: Most Recent Order Identification

* **Database:** `ProductOrders`
* **Objective:** Identify each customer's latest order date using aggregated subquery grouping (`MAX()`) and date conversions (`CONVERT`).

### Question 10: Sales Rep Performance vs. Company Total

* **Database:** `Examples`
* **Objective:** Compute the percentage of overall company historical sales generated by each sales rep in 2014 using a `CROSS JOIN` subquery for total aggregation and percentage formatting (`P2`).

---

## Key T-SQL Functions & Concepts Used

* **Set Operations & Logic:** `EXCEPT`, `IN`, `NOT IN`, `CASE...WHEN...THEN`
* **Date Manipulation:** `DATENAME()`, `DATEPART()`, `DATEDIFF()`, `CONVERT()`
* **Formatting:** `FORMAT()`, `CONCAT_WS()`
* **CTEs:** `WITH` clause construct for modular query breakdown.
